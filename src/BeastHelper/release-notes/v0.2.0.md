# BeastHelper v0.2.0

闘獣練（Crucible of the Unbroken）向けの大型アップデートです。

> ⚠️ 自動化系の機能は**すべて初期状態でオフ**で、使用は自己責任です（ゲーム内の自動操作は FFXIV の利用規約に抵触します）。各機能は闘獣練のコンテンツ内・画面に限定して動くようにしています。

## 新機能：闘獣練の自動化

- **自動突入ループ**：エントリーNPCへの移動・会話、盤面選択、周回回数の指定。
- **魔獣編成**：編成モードを3つから選択。
  - **おすすめ（安定重視）**：レベル・ティア・防御ステータスから安定して戦える編成を自動選出（プレビュー付き）。
  - **レベリング（低ランク優先）**：ランクの低い魔獣を優先して育成。
  - **手動**：魔獣リストでチェックした魔獣で編成。
- **盤面ごとの編成上限に対応**：第一盤10／第二盤12／第三盤14／特一盤12／特二盤15。
- **呼び笛の割り当て＆戦闘開始**の自動化。
- **宝箱の自動選択**（優先キーワード順）、**ショップの自動購入**（回復／装備／エサ）。
- **回復薬・強化/攻撃アイテムの自動使用**（条件ルール対応）。
- **AutoDuty 連携**：盤面ループ全体を AutoDuty に委譲するモード。
- **BMR 回避連携 / RSR 連携**（任意）。

## ランク・経験値の同期

- **魔獣手帳を開くだけで全50体のランク／経験値を自動取得**できるようになりました。
- 詳細パネルにカーソルを合わせたときの受動取得も改善。
